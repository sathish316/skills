# Good-to-Have Skills

Skills from other repos worth installing when needed.

## From [mattpocock/skills](https://github.com/mattpocock/skills)

### teach

Turns Claude Code into a stateful personal tutor for any topic — tracks your mission, learning records, and zone of proximal development across sessions, producing beautiful self-contained HTML lessons and reference cheat sheets grounded in high-trust external resources.

**Usage:** Run `/teach <topic>` to start or continue a multi-session learning journey; Claude maintains `MISSION.md`, `learning-records/`, `lessons/`, and `reference/` in the current workspace so each session builds on the last.
